1. Upload index.html, package.json and capacitor.config.json to a new GitHub repository (plain files only, no folders).
2. In the repository click Add file > Create new file. In the name box type exactly:  .github/workflows/build-apk.yml
3. Paste the full contents of build-apk.yml (from this folder) and click Commit changes.
4. Open the Actions tab, run "Build YouPlay APK", then download the YouPlay-APK artifact.
